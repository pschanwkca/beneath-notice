# BENEATH NOTICE 視線之下

一個 5 公分高的科學家爸爸和隊友，在屋企裡探險、互相幫忙通關的瀏覽器原型（Three.js）。
最終會移到 Unreal Engine 5，這個版本用來試玩法和手感。

## 一個連續的世界（無縫，不轉場）
地庫、牆內、廚房、客廳、車房、後園、鄰居的陽光房全部在同一個世界裡，用真的隧道、門和洞連住，**行過去就到**，中途不會黑畫面、不會載入。
- 地庫的老鼠洞 → 一條隧道 → 牆內空間；沿牆爬到頂，經缺口邊的木板爬上夾層 → 老鼠洞 → 廚房。
- 廚房右邊的門通往客廳／飯廳。門被門擋卡住：熊推一下，或者爸爸把門擋縮小，一陣風就會把門吹開。
- 客廳盡頭牆腳的通風口（拿到電池後打開）→ 一條短風管 → 車房（落在紙箱上面）。
- 車房側門下面的狗門（門扣太高，要疊羅漢或推木箱墊腳）→ 自己屋的後園 → 圍欄最底的爛板 → 陳伯的後園 → 露台 → 陽光房的貓門。
- 進入新地方時，章節名稱只會在畫面上淡入淡出，遊戲不會停。
- 往後的新場景都會用同一個方法接上去。

## 玩法重點
- **不能被人看見**：被看見太久會「定型」變成玩具，被太太收進玩具箱。
- **疊羅漢**（F）：只會疊上最近、最近距離的隊友；第三個人要走到最頂那個人旁邊再按 F，如此類推。最頂的人可以把下面的人拉上去。
- **玩具箱救人**：爬進玩具箱搖醒隊友（100%），或用 Prototype（R，體力上限 -20%）。
- **甚麼都可以放大縮小**：爸爸的尺寸槍；可以改變尺寸的東西有描邊（只在爸爸操控時顯示）。毛公仔放大變彈床，曲奇放大全隊一起吃。
- **熊可以推所有可推的東西**（左鍵）。

## 角色（共 10 隻）
| 角色 | 能力 |
|---|---|
| 爸爸（老鼠，科學家） | 尺寸槍：左鍵放大、右鍵縮小 |
| 助手（鼯鼠，研究生） | 空中按住 Space 滑翔；左鍵抱隊友一齊飛；右鍵偵察視線 |
| 老友（熊，水電師傅） | 左鍵推一下／按住推着走 |
| 小彩（變色龍，實習生） | 停着不動變色隱身；左鍵吐舌頭拿東西或拉自己過去 |
| 阿刺（刺蝟，搬運工） | 左鍵縮成一團衝出去，撞跌擋路的東西 |
| 跳跳（兔，技術員） | 按住左鍵蓄力，放手跳得好高 |
| 阿浣（浣熊，保安） | 左鍵把小石子彈到準星位置，聲音會引開太太和貓 |
| 阿蛙（青蛙，工程師） | 按住左鍵蓄力遠跳；在插座、燈或電視旁按 E：附近熄燈 20 秒，全隊在黑暗裡更難被看見 |
| 阿蝠（蝙蝠，夜更研究員） | 空中再按 Space 拍翼（3 下），按住慢慢飄落；撞到天花或枱底按住 Space 倒吊，可以沿底面爬、爬到邊翻上面，倒吊時回體力；左鍵回聲定位：附近在看守的人、動物和電池隔牆都看得到 |
| 阿龜（烏龜，園藝研究員） | 左鍵縮入殼：看起來只是一塊石頭，幾乎不會被看見；隊友可以踩上殼當踏腳 |

後面六隻是 Origin Dynamics 的員工，要在單人故事裡解鎖，解鎖後多人模式先可以揀：
- 阿刺：完成序章（地庫）
- 跳跳：完成第一章（把核心帶回牆腳）
- 阿浣：完成第二章（客廳的電池）
- 阿蛙：單人模式集齊全部鈕扣電池（現在共 10 粒）
- 阿蝠：第三章在車房工作枱底找到佢，佢會加入單人隊伍
- 阿龜：第四章在陳伯的後園找到佢（扮成一塊石頭），佢會加入單人隊伍

開始畫面的「角色」可以看到全部角色；未解鎖的只會顯示黑色剪影和「?」，以及解鎖方法。之後的章節會加入更多角色。
解鎖紀錄存在這部機的瀏覽器裡。

## 單人故事
序章（地庫）→ 第一章（牆內 → 廚房：找回核心）→ 第二章（客廳：拿遙控器的電池替核心充電）
→ **第三章（車房）**：Origin Dynamics 的職員拿着電筒巡車房，鐵架頂仲有部監視鏡頭。上工作枱、從舊收音機拆線圈、裝上爸爸的機座，再打開狗門的門扣逃出去。躲在車底比較安全。
→ **第四章（後園與鄰居家）**：在長草裡躲、避開灑水器，鑽過圍欄的爛板去陳伯的後園。陳伯的狗醒了會吠，陳伯會抬頭望出來。由貓門入陽光房，爬上書枱旁邊的紙箱和書，拿走控制晶片。

開始畫面的「選擇章節」可以直接由已解鎖的章節開始（完成第一章解鎖第二章，完成第二章解鎖第三章，走出車房解鎖第四章）。

## 測試模式
「選擇章節」左下角有個「測試模式」開關（或者喺網址後面加 `?test`）。開咗之後：
- 每一章都可以直接開始；測試期間解鎖嘅嘢唔會儲存，唔會影響真正進度
- 暫停選單會多咗「測試工具」：一按就跳去地庫、牆內、廚房、客廳、通風口、車房、工作枱、狗門、後園、圍欄爛板、陽光房、書枱等位置（只係搬位置，唔會改任務）
- 開關：不會被發現、無限體力；「全部角色加入隊伍」會將 10 隻角色全部加入單人隊伍
- 畫面底部會顯示「測試模式」，提你而家唔係正常玩緊
- 只限單人模式；多人連線時測試工具會收埋

## 多人連線（一齊通關，最多 8 人）
1. 開始畫面按「多人連線」→「開新房間」，會得到 4 位房號。
2. 按「複製邀請連結」傳給朋友，或者叫朋友輸入房號加入。
3. 每人揀一隻角色；四隻主角沒有人揀就由電腦控制，跟着房主行動。
4. 房主按「開始」，大家由廚房開始（多人故事線和單人不同，以目標為主）：
   - 第一章：找齊三個零件（彈簧、鏡片、電容）→ 打開往客廳的門 → 全隊進入客廳 → 拿遙控器的電池
   - 第二章（車房）：全隊爬過通風口 → 弄跌鐵架頂的監視鏡頭 → 打開狗門的門扣 → 全隊出後園
   - 第三章（後園）：全隊穿過圍欄的爛板 → 全隊由貓門入陽光房 → 拿走書枱上的控制晶片
5. 遊戲中按 **Esc**：會顯示房號和「複製邀請連結」，可以「離開房間，返回主畫面」。多人遊戲不會暫停。

規則：
- 每個人只會被自己的視線條「定型」；被看見的人變成玩具，其他隊友去玩具箱搖醒他，或者任何人按 R 用 Prototype。
- 全部玩家都變成玩具才算失敗，回到存檔點。
- **斷線重連**：用同一部機、同一個瀏覽器，打開原本的邀請連結或輸入同一個房號，就會自動拿回原本的角色。
- **中途加入**：遊戲開始後，新朋友入房可以揀一隻空位的角色加入。
- 房主斷線的話，這局會結束。

技術：
- 點對點 WebRTC（[Trystero](https://github.com/dmotz/trystero)，用公共 Nostr relay 配對），不需要伺服器。
- 房主負責家人、貓、物件、門、玩具和拾取物；每個玩家負責自己的角色。
- 少數公司／學校網絡會擋 WebRTC，連不上時試下用另一個網絡（例如手機熱點）。
- 在同一部電腦測試：網址加 `?net=local`，開兩個分頁就可以互連（用 BroadcastChannel）。

## 手機
- 觸控操作：左邊搖桿移動、右邊拖動轉視角、按鈕使用能力。
- 手機版自動用低畫質：不用 MSAA 改用 FXAA、陰影隔一格畫面更新一次、光暈半解像度、毛髮層數減少；
  幀數不夠時會自動降低解像度，夠快時再調高。
- 任務卡片會收起說明，點一下可以再看。

## 本地開發
```bash
bash build.sh            # 把 src/ 合併成 index.html
```
直接用瀏覽器開 `index.html` 就可以玩（需要網絡載入 three.js）。

## 結構
- `src/head.html` 介面和樣式
- `src/e8_world.js` 連續世界：每個地方的位置、只畫附近的地方、固定數量的燈（不會重新編譯 shader）、分區碰撞
- `src/e7_living.js` 客廳／飯廳、門、通風口和多人目標清單
- `src/e11_garage.js` 車房（第三章）：Origin Dynamics 職員的巡邏和電筒、監視鏡頭、工作枱、狗門
- `src/e14_test.js` 測試模式：跳位置、不會被發現、無限體力、全員加入
- `src/e13_newcrew.js` 阿蝠和阿龜：模型、倒吊、回聲定位、縮殼、劇情中加入
- `src/e12_yard.js` 後園和陽光房（第四章）：夜空、長草、鄰居的狗、陳伯、灑水器、控制晶片；多人目標和同步
- `src/e9_crew.js` Origin Dynamics 四隻新角色和能力
- `src/g_net.js` 多人連線（大廳、同步、房主規則）
- `vendor/trystero.iife.js` 打包好的 Trystero（MIT）
- `test/run.mjs` Playwright 自動測試（`node test/run.mjs <steps>`），`test/steps_world.json` 走一次整個連續世界
- `test/mp2.mjs` 兩個玩家行一次多人第一章；`test/mp3.mjs` 行車房和後園；`test/steps_audit.json` 檢查有沒有隱形牆（沒有東西的碰撞箱）
