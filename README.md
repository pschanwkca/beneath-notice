# BENEATH NOTICE 視線之下

一個 5 公分高的科學家爸爸和隊友，在屋企裡探險、互相幫忙通關的瀏覽器原型（Three.js）。
最終會移到 Unreal Engine 5，這個版本用來試玩法和手感。

## 一個連續的世界（無縫，不轉場）
地庫、牆內、廚房、客廳、車房、後園、鄰居的陽光房全部在同一個世界裡，用真的隧道、門和洞連住，**行過去就到**，中途不會黑畫面、不會載入。
- 地庫的老鼠洞 → 一條隧道 → 牆內空間；沿牆爬到頂，經缺口邊的木板爬上夾層 → 老鼠洞 → 廚房。
- 廚房右邊的門通往客廳／飯廳。門被門擋卡住：熊推一下，或者爸爸把門擋縮小，一陣風就會把門吹開。
- 客廳盡頭牆腳的通風口（拿到電池後打開）→ 一條短風管 → 車房（落在紙箱上面）。
- 車房側門下面的狗門（門扣太高，要疊羅漢或推木箱墊腳）→ 自己屋的後園 → 圍欄最底的爛板 → 陳伯的後園 → 露台 → 陽光房的貓門。
- 陽光房 → 陳伯前園的閘門底（有條縫）→ 行人路 → 落街（路邊石 15 cm）→ 斑馬線 → 中間的安全島 → 對面行人路 → 公園鐵閘。
- 進入新地方時，章節名稱只會在畫面上淡入淡出，遊戲不會停。
- 往後的新場景都會用同一個方法接上去。

## 開始畫面和準備區
- 開始畫面係一個安靜嘅工作枱：大家企喺度，間中轉吓頭；爸爸揮手、小彩揮返；跳跳同阿刺慢慢行過；青蛙間中跳一下、阿蝠拍翼、阿龜縮殼。冇 sticker、冇亂飛。
- **每一局都由縮小機入面嘅準備區開始**（單人同多人都係）：浮喺光隧道入面嘅平台，有幾嚿可以練爬嘅嘢。企上出口前面嘅光圈就出發（多人要全部玩家企齊）——白光一閃，大家由真正嘅縮小機環度跌出嚟，落喺工作枱上面。
- **表情**：按住 T 揀（或者 1–8）；手機按「表情」。每隻角色嘅表情都係用自己嘅樣整嘅 sticker，會喺頭頂彈出嚟，角色都會做埋動作；多人模式大家都睇到。
- **卡住咗**：長按 K（或者暫停選單「我卡住了」，手機一樣用得）會送你返剛才企得穩嘅位置（最少離開 8 步）；30 秒內再按會再退後啲，最後會送返存檔點；多人可以揀「去隊友身邊」。陷咗入嘢入面或者跌出地圖會自動救返。暫停選單可以複製卡住嘅位置，方便報 bug。

## 玩法重點
- **不能被人看見**：被看見太久會「定型」變成玩具。看見你的人會把玩具執走，放到每一關固定的地方：
  | 地方 | 誰執 | 放去邊 |
  |---|---|---|
  | 飯廳／客廳 | 太太 | 玩具箱 |
  | 車房 | Origin Dynamics 職員 | 證物箱（車頭旁邊的透明膠箱） |
  | 後園 | 陳伯的狗 | 狗屋 |
  | 陽光房 | 陳伯（用夾） | 書枱 |
  | 馬路 | 遛狗的人 | 藍色回收桶 |
- **疊羅漢**（F）：只會疊上最近、最近距離的隊友；第三個人要走到最頂那個人旁邊再按 F，如此類推。最頂的人可以把下面的人拉上去。
- **救人**：
  - 玩具還在地上、未被執走：隊友企在旁邊一陣就可以搖醒他（100%）。
  - 已經被執走：一定要用 Prototype（R，體力上限 -20%）。要有人行到那個地方、**企在玩具旁邊並面向他**才用得到，不可以隔空按 R。
  - 用完 Prototype 要再找 Prototype 藥水補充。
- **甚麼都可以放大縮小**：爸爸的尺寸槍；可以改變尺寸的東西有描邊（只在爸爸操控時顯示）。毛公仔放大變彈床，曲奇放大全隊一起吃。
- **熊可以推，也可以拉**：左鍵推；**按住右鍵**捉住東西拉着行（手機按「拉」）。拉的時候行得慢、不可以跑和跳，東西越大越慢。

| 阿鼴（星鼻鼴鼠，地質研究員） | 左鍵喺草地、泥土或沙上鑽入地底：冇人睇到、狗都聞唔到；喺地底慢慢行，遇到硬地（路、地磚、地板）就過唔到；再按一下（或 Space）鑽出嚟 |

後面七隻是 Origin Dynamics 的員工。**多人模式一開始就有 8 隻可以揀**（四隻主角 + 阿刺、跳跳、阿浣、阿蝠），夠 8 個人一齊玩；阿蛙、阿龜、阿鼴要喺單人故事解鎖先揀得。單人模式入面，佢哋喺故事入面遇到先會加入：
- 阿刺：完成序章（地庫）
- 跳跳：完成第一章（把核心帶回牆腳）
- 阿浣：完成第二章（客廳的電池）
- 阿蛙：單人模式集齊全部鈕扣電池
- 阿蝠：第三章在車房工作枱底找到佢，佢會加入單人隊伍
- 阿龜：第四章在陳伯的後園找到佢（扮成一塊石頭），佢會加入單人隊伍
- 阿鼴：第六章在公園的沙池找到佢（躲咗喺沙底三日），佢會加入單人隊伍

開始畫面的「角色」可以看到全部角色；未解鎖的只會顯示黑色剪影和「?」，以及解鎖方法。之後的章節會加入更多角色。
解鎖紀錄存在這部機的瀏覽器裡。

## 單人故事
序章（地庫）→ 第一章（牆內 → 廚房：找回核心）→ 第二章（客廳：拿遙控器的電池替核心充電）
→ **第三章（車房）**：Origin Dynamics 的職員拿着電筒巡車房，鐵架頂仲有部監視鏡頭。上工作枱、從舊收音機拆線圈、裝上爸爸的機座，再打開狗門的門扣逃出去。躲在車底比較安全。
→ **第四章（後園與鄰居家）**：在長草裡躲、避開灑水器，鑽過圍欄的爛板去陳伯的後園。陳伯的狗醒了會吠，陳伯會抬頭望出來。由貓門入陽光房，爬上書枱旁邊的紙箱和書，拿走控制晶片——章節完咗之後故事繼續，由前閘出去。
→ **第五章（馬路）**：日頭嘅街，有個人拖住隻小白狗散步（狗會嗅到你、吠）。斑馬線燈柱半腰有個黃色「過路」掣，爬上去按，等綠色公仔燈先過。車輪會輾人（回到存檔點），但車身底下夠高，車喺頭頂飛過只會被吹跌。5 cm 嘅腳步行唔晒成條馬路：中間安全島可以等，島上嘅柱都有掣；或者按住 Shift 跑。過咗馬路就直接行入公園（唔使轉場）。
→ **第六章（公園）**：日頭嘅楓林公園，陽光猛烈。晶片要喺陽光底下先會充電，最開揚嘅地方係遊樂場滑梯塔頂。狗場入面兩個狗主坐喺長椅傾偈，佢哋嘅金毛同小白狗追波（狗會嗅到你、會吠，狗主會望過嚟）；遊樂場有兩個小朋友：小女孩玩韆鞦、間中走去騎彈弓鴨，小男孩張開雙手扮飛機周圍跑、喺沙池邊掘沙（佢嘅腳會踢跌你），佢哋媽媽坐喺西邊長椅睇住佢哋——間中會望手機，嗰陣先最好過；有個戴太陽眼鏡嘅人沿住環形路跑步（佢嘅腳會踢跌你）；滑板場有個少年踩滑板（撞到會被撞飛）。長草可以躲，樹蔭底下比較難被發現。去到遊樂場，沙池入面有嘢郁——係阿鼴。爬梯或者攀網上塔頂，放低晶片：要守大約 45 秒等佢充滿電，雲遮住太陽嗰陣會停；中途小白狗會走出狗場嚟遊樂場周圍嗅。充滿電拎返晶片，由公園後門出去完章——對面就係楓林小學（第七章：學校，製作中）。滑梯可以滑落嚟！被發現變咗玩具嘅話，金毛會以為係新玩具，咬去狗主嘅狗玩具桶。

開始畫面的「選擇章節」可以直接由已解鎖的章節開始（完成第一章解鎖第二章，完成第二章解鎖第三章，走出車房解鎖第四章，拿到晶片解鎖第五章，過了馬路解鎖第六章）。

## 活的屋企（廚房、客廳、廁所、樓上）
- **開關**（電腦按 **E**，手機按「用」；走近時會有一個青色光圈）：廚房燈掣、廁所燈掣（連抽氣扇）、洗碗盆水龍頭、抽油煙機、馬桶（沖廁）、電視、落地燈。多人同步，任何角色都可以用。
  - 熄廚房燈：廚房暗了很難被看見——太太會走過來開返。
  - 開水龍頭：洗碗盆會慢慢儲水，人在裡面會浮起來。
  - 抽油煙機：好嘈，開着的時候家人聽不清細微的聲音；但風扇在轉，就上不了煙囱。
  - 沖廁：全屋都聽到。站在馬桶裡沖廁會被沖走，從雪櫃底下的去水口冒出來。
- **廁所**（雪櫃旁邊的門）：紙皮石地磚、可以爬的馬桶和水箱、洗手盆、鏡櫃（爬上去）、毛巾、膠洗衫籃。有人用廁所時門會關上。
- **天花風喉**（秘密通道）：爐頭開着的火會把你托上抽油煙機 → 爬煙囱上天花 → 沿風喉去到廁所的抽氣扇 → 跌落洗衫籃。抽氣扇和廁所燈連在一起，燈開着就過不了。
- **家人的腦**：太太和女兒會按自己的需要做事（煮飯、洗碗、打電話、望出窗、用廁所、做功課、睇電視、逗貓、問爸爸幾時回來……），每次揀的都不同，不會再兜圈。
  - 你搞過的嘢她們會發現並走去處理（熄燈、開水、沖廁、電視、落地燈）。
  - 疑心有四級：平靜 → 覺得怪怪的 → 起了疑心（眼睛更利，會返去發生過怪事的地方查看）→ 搜屋（太太叫女兒一起找）。靜一段時間會慢慢冷靜。
  - 畫面上方的眼睛下面會寫她們在哪個房間和疑心程度。
  - 她們會互相對話；只有附近的玩家看到字幕。

## 車房和陳伯（第二期）
- **天花風喉通到車房**：由廁所抽氣扇之前分岔，經客廳天花，去到車房天花的通風格——正正在鐵架頂（監視鏡頭）上面。鏡頭的電線由鐵架頂直上通風格，可以爬返上風喉。屋企和車房之間來回很快。
- **車房的開關**：電箱（車房燈全熄，只剩職員的電筒）、監視鏡頭的拖板（斷電之後鏡頭甚麼都看不到）、工作枱上的舊收音機（播舊歌，蓋過細微聲音）。
- **Origin Dynamics 職員的腦**：不再行固定路線——會自己揀搜邊度（鐵架、車、工作枱、垃圾桶、狗門、鏡頭），亦會用對講機（望着手機時看不到你）；你搞過的開關他會去整返；疑心四級，最高會加快腳步、電筒亂照搜車房。
- **陳伯**：看報紙、望出窗、飲茶、瞌眼瞓（閉着眼，看不到你）、聽粵曲（收音機）。熄了他的落地燈他會更容易睡着；收音機開着他會閉眼聽，聽到一半熄了他會醒來起疑。
- **後園水龍頭**：關了灑水器就會停。

## 樓上：樓梯和女兒的房間（第三期）
- **樓梯**：客廳後牆開了一道門，入面是真正的樓梯——十六級，對五厘米高的人來說每級都要爬。樓梯鋪了地毯，好抓手：一撞上去就會一下攀上去（按住 Shift 跑會快好多）。落樓就一級一級跳落去，很快。轉角平台、走廊、牆上一路有家庭相。
- **秘密路線**：天花風喉（客廳那段）有個地台通風口直通女兒房——由廚房抽油煙機的熱風升上去，沿風喉行到透光的地方，攀上去就到。站上通風格就會跌返落風喉，是落樓的捷徑。
- **女兒的房間**：會彈的床（跳上去試試）、床底可以躲、星星被、書枱（抽屜櫃可以爬上去）、牆上貼着她畫給爸爸的畫、她的日記（行到旁邊就會讀到）、方格書架頂的音樂盒、梳妝櫃、衣櫃（踩着收納箱一路爬上頂有電池）、窗邊的窗台座——她的小熊坐在窗口等爸爸回家。
- **四個開關**：房間燈（門口梳妝櫃上面）、書枱燈、星空投影燈（天花變成星空）、音樂盒。**音樂盒一響全屋都聽得到**——女兒會即刻跑上樓關掉，她不在就輪到太太上去。適合分隊：兩個人上樓扭音樂盒，其他人在樓下做事。音樂盒大約一分鐘後會自己慢慢停。
- **一家人都會上樓**：女兒會上樓畫畫、聽音樂盒、躺在床邊看星星（有時會忘記熄燈）；太太會上樓執衣服、望望窗口的小熊、順手熄掉女兒忘了關的燈。燈光照到的地方她們看得到你，月光從窗口照入來的那一片也是。

## 語音和打字（多人，好似 PEAK）
- **近距離語音**：隊友越近越大聲，聲音從他站的方向傳過來；隔住牆或者在另一個房間會悶聲，走遠了就聽不到。變成玩具都可以講嘢（叫人救）。
- 入房間時瀏覽器會問咪權限；房間裡（未開始）大家都聽得到大家。
- 咪：**開咪**（預設）／**按住 V 講**／**關**，在暫停選單揀；**M** 靜音／解除。暫停選單仲有「語音音量」。
- **Enter** 打字（最多 80 字），字會在角色頭上出泡泡，左邊有對話紀錄；Esc 取消。
- 說話中的隊友：頭像會發光、名牌有聲波；關了咪的隊友頭像有紅色咪標記。
- 手機：左邊有「咪」和「聊天」掣。
- 建議戴耳筒，避免回音。

## 音樂
- 方向：「細細粒嘅偷偷摸摸」——細編制室內樂：毛氈鋼琴、撥弦、低音大提琴、鋼片琴、單簧管／巴松管、刷鼓，暖暖的小房間混響。全部在瀏覽器即時合成，沒有音樂檔案。
- 一條原創主題旋律貫穿全部章節，每個地方換編曲：標題（鋼琴獨奏）、地下實驗室（鋼片琴）、牆內（鋼琴＋撥弦）、飯廳客廳（撥弦＋單簧管，最偷偷摸摸）、車房（巴松管、低音、脈搏）、後園（夜曲）、馬路（刷鼓 jazz 三重奏）。
- 音樂跟住玩法變：收埋唔郁只有鋼琴和低音 → 行動加撥弦 → 行近大人主旋律出場 → 被看見弦樂顫音和心跳。
- 變成玩具、救回隊友、完成目標各有一小段提示音。
- `node test/music_render.mjs` 會把每段編曲離線輸出成 WAV（試聽和量度用）。
- 暫停選單有「音樂」音量（和「音量」分開）。

## 測試模式
「選擇章節」左下角有個「測試模式」開關（或者喺網址後面加 `?test`）。開咗之後：
- 每一章都可以直接開始；測試期間解鎖嘅嘢唔會儲存，唔會影響真正進度
- 暫停選單會多咗「測試工具」：一按就跳去地庫、牆內、廚房、客廳、通風口、車房、工作枱、狗門、後園、圍欄爛板、陽光房、書枱等位置（只係搬位置，唔會改任務）
- 開關：不會被發現、無限體力；「全部角色加入隊伍」會將 10 隻角色全部加入單人隊伍
- 畫面底部會顯示「測試模式」，提你而家唔係正常玩緊
- 只限單人模式；多人連線時測試工具會收埋

## 多人連線（一齊通關，最多 8 人）
1. 開始畫面按「多人連線」，輸入你的名字 →「開新房間」，會得到 4 位房號。
2. 按「複製邀請連結」傳給朋友，或者叫朋友輸入房號加入。
3. **揀角色頁**：大家揀咗嘅角色企喺各自嘅發光台上（你係琥珀色、隊友係青色），頭頂有玩家名；左邊資料卡顯示角色能力（速度、攀爬、潛行），底部一排頭像揀角色（一開始有 8 隻揀得；未解鎖嘅係黑影，hover 可以睇資料）。四隻主角沒有人揀就由電腦控制。名字可以隨時改，遊戲入面嘅名牌、聊天都會用。
4. 房主按「開始」，大家喺準備區集合，全部人企上出口前面嘅光圈就一齊出發（多人故事線和單人不同，以目標為主）：
   - 序章（地庫今晚冇人）：離開工作枱 → 去牆腳的裂縫搵前拍檔 → 跟佢入牆 → 沿牆身爬上廚房
   - 第一章（次序隨意，可以分頭行動）：三個零件——彈簧（爐頭旁）、電容（洗手盆下的櫃）、鏡片（廁所鏡櫃）；打開往客廳的門；拿遙控器的電池 → 全隊進入客廳 → 爬過通風口。任務卡會顯示哪些已經完成
   - 第二章（車房）：全隊爬過通風口 → 弄跌鐵架頂的監視鏡頭 → 打開狗門的門扣 → 全隊出後園
   - 第三章（後園）：全隊穿過圍欄的爛板 → 全隊由貓門入陽光房 → 拿走書枱上的控制晶片
   - 第四章（馬路）：全隊由前閘底鑽出去 → 按過路燈的掣 → 全隊過馬路 → 全隊到公園門口
   - 第五章（公園）：全隊到遊樂場 → 爬上滑梯塔頂放低晶片 → 守住晶片等佢充滿電（雲遮太陽會停）→ 拿回晶片 → 全隊從公園後門出去（完）
5. 遊戲中按 **Esc**：會顯示房號和「複製邀請連結」，可以「離開房間，返回主畫面」。多人遊戲不會暫停。

規則：
- 每個人只會被自己的視線條「定型」；被看見的人變成玩具，執玩具的人會把他放到那一關的地方；未被執走之前隊友可以企在旁邊搖醒他，被執走之後就要有人去到那裡、面向他按 R 用 Prototype。
- 全部玩家都變成玩具才算失敗，回到存檔點。
- **斷線重連**：用同一部機、同一個瀏覽器，打開原本的邀請連結或輸入同一個房號，就會自動拿回原本的角色。
- **中途加入**：遊戲開始後，新朋友入房可以揀一隻空位的角色加入。
- 房主斷線的話，畫面頂會出現提示，等 45 秒畀房主重連（可以撳「重新加入」）；等唔到先會結束。網絡唔穩時都會有提示。
- **存檔**：房主部機會自動儲存多人進度（任務、存檔點、拎咗嘅零件同電池、開咗嘅門）。下次開房，揀角色頁可以揀「繼續上次進度」或者「由頭開始」；揀繼續的話，準備區嘅出口會直接送大家返上次嘅存檔點。
- **變咗玩具**：可以按 Tab／← → 睇隊友嘅畫面（手機按 ‹ ›），救返之後自動返自己。
- **連線紀錄**：玩得唔順、斷線或者卡住，暫停選單撳「複製連線紀錄」，就會複製一段文字（邊個幾時入房／斷線、每個隊友嘅 ping 同連線方式、fps、救返同卡住嘅位置、錯誤），貼畀開發者睇。

技術：
- 點對點 WebRTC（[Trystero](https://github.com/dmotz/trystero)，用公共 Nostr relay 配對），不需要伺服器。
- 房主負責家人、貓、物件、門、玩具和拾取物；每個玩家負責自己的角色。
- 配對同時用幾個 Nostr relay；之後玩家用自己嘅網絡直接連埋一齊（Google／Cloudflare STUN 幫手搵路），中間冇中轉伺服器。
- 角色位置每秒 20 次同步，對方會用短預測補返中間，郁得順啲。
- 少數公司／學校網絡會擋 WebRTC，連不上時試下用另一個網絡（例如手機熱點）。
- 在同一部電腦測試：網址加 `?net=local`，開兩個分頁就可以互連（用 BroadcastChannel）。

## 手機
- 觸控操作：左邊搖桿移動、右邊拖動轉視角、按鈕使用能力。
- 手機版自動用低畫質：不用 MSAA 改用 FXAA、陰影隔一格畫面更新一次、光暈半解像度、毛髮層數減少；
  幀數不夠時會自動降低解像度，夠快時再調高。
- 任務卡片會收起說明，點一下可以再看。
- 右下角動作掣排成弧形；左邊中間係「表情」（多人再加「咪」同「聊天」）。名冊、說明等面板右上角有 ×，點背景都可以閂。
- 轉打橫／打直會自動重新排版。

## 日夜
- 成個世界都係同一個夏天下晝，由地庫一路連到公園：室外係藍天、太陽、白雲，太陽係一盞有影嘅大燈；街燈、車頭燈、窗燈都唔開。
- 室內窗外係日頭嘅街景（藍天、樹、鄰居屋），向住太陽嘅窗（廚房、樓梯平台、地庫）有陽光射入嚟（一道光柱、地上一塊光斑），其他窗有柔和嘅日光。屋入面嘅燈照開，屋企嘅劇情（煮晚飯、女兒玩星星燈）都照舊。日頭開星空投影燈，女兒房嘅窗簾會自動拉埋（房間暗咗，星星先睇得到；窗口嗰度亦冇咗陽光，比較易匿）。
- 屋企外面：由後園同馬路望返轉頭，屋有斜屋頂（磚煙囱）、車房有人字屋頂（向後園嗰面有圓形通風口）、簷篷、水渠同去水管；車房向後園嗰幅牆有個窗，百葉簾拉埋（車房入面都一樣，所以熄燈照樣夠黑）。
- 日頭嘅客廳：窗唔向太陽，所以加咗柔和嘅日光反射，室內空氣都清啲；電視播緊卡通風景（關電視就黑畫面）。地庫老鼠洞嗰角加咗少少日光。
- `src/a_core.js` 入面嘅 `DAY` 改做 `false` 就會變返夜晚版本（星空、月光、街燈、黃昏窗景）。
