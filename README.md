# BENEATH NOTICE 視線之下

一個 5 公分高的科學家爸爸和隊友，在屋企裡探險、互相幫忙通關的瀏覽器原型（Three.js）。
最終會移到 Unreal Engine 5，這個版本用來試玩法和手感。

## 玩法重點
- **不能被人看見**：被看見太久會「定型」變成玩具，被太太收進玩具箱。
- **疊羅漢**（F）：隊友一個踩一個上去，最上面的人再把其他人拉上來。
- **玩具箱救人**：爬進玩具箱搖醒隊友（100%），或用 Prototype（R，體力上限 -20%）。
- **甚麼都可以放大縮小**：爸爸的尺寸槍；毛公仔放大變彈床，曲奇放大全隊一起吃。
- 角色：爸爸（尺寸槍）、助手／鼯鼠（滑翔、抱人、偵察）、老友／熊（推）、小彩／變色龍（變色、舌頭）。

## 多人連線（一齊通關，最多 4 人）
1. 開始畫面按「多人連線」→「開新房間」，會得到 4 位房號。
2. 按「複製邀請連結」傳給朋友，或者叫朋友輸入房號加入。
3. 每人揀一隻角色；沒有人揀的角色由電腦控制，跟着房主行動。
4. 房主按「開始」，大家由第一章（牆內 → 廚房）一齊玩。

規則：
- 每個人只會被自己的視線條「定型」；被看見的人變成玩具，其他隊友去玩具箱搖醒他，或者任何人按 R 用 Prototype。
- 全部玩家都變成玩具才算失敗，回到存檔點。
- 疊羅漢、鼯鼠抱人可以用到其他玩家的角色（會暫時「借用」那隻角色）。

技術：
- 點對點 WebRTC（[Trystero](https://github.com/dmotz/trystero)，用公共 Nostr relay 配對），不需要伺服器。
- 房主負責家人、貓、物件、玩具和拾取物；每個玩家負責自己的角色。
- 少數公司／學校網絡會擋 WebRTC，連不上時試下用另一個網絡（例如手機熱點）。
- 在同一部電腦測試：網址加 `?net=local`，開兩個分頁就可以互連（用 BroadcastChannel）。

## 本地開發
```bash
bash build.sh            # 把 src/ 合併成 index.html
```
直接用瀏覽器開 `index.html` 就可以玩（需要網絡載入 three.js）。

## 結構
- `src/head.html` 介面和樣式
- `src/a_core.js` … `src/z_boot.js` 遊戲程式，按檔名次序合併
- `src/g_net.js` 多人連線（大廳、同步、房主規則）
- `vendor/trystero.iife.js` 打包好的 Trystero（MIT）
- `test/run.mjs` Playwright 自動測試（`node test/run.mjs <steps>`）
- `test/mp.mjs` 兩個玩家的連線測試（同一個瀏覽器、兩個分頁）
